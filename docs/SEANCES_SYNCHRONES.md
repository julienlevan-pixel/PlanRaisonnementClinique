# Animer une séance synchrone

Pour réunir plusieurs PRC sous un seul code, utiliser **Mes séances** : [organisation et bilan multi-cas](SEANCES_MULTICAS.md). Les commandes ci-dessous restent celles de chaque cas.

Le panel expert et le groupe étudiant sont deux activités distinctes, avec des codes différents. Le corrigé du panel doit être généré et validé avant de créer le groupe étudiant. Son barème reste personnalisable pour les prochains groupes.

1. Dans le PRC, choisissez **Synchrone** pour le panel ou le groupe étudiant, puis lancez l’activité. Les nouveaux participants arrivent dans une salle d’attente après avoir indiqué leur nom ou pseudonyme. Aucun compte participant n’est nécessaire.
2. Cliquez sur **Ouvrir la projection** et placez cet onglet sur l’écran collectif. Le QR code, le code d’accès et le nombre de personnes ayant rejoint la séance y sont affichés. Ce compteur indique des participations enregistrées, pas une présence en ligne instantanée.
3. Depuis votre écran de pilotage, cliquez sur **Présenter le cas**. Le scénario, les consignes et les observations deviennent visibles sur la projection et les appareils. Les réponses restent bloquées.
4. Cliquez sur **Ouvrir les réponses** lorsque tout le monde peut commencer. Vous pouvez auparavant indiquer une durée de 1 à 180 minutes, ou laisser le champ vide. Le cas reste projeté pendant que chacun choisit ses deux impressions cliniques et les cinq données discriminantes pour chacune. Les experts attribuent également une importance de 1 à 3 à chaque donnée choisie ; les étudiants ne le font pas.
5. Suivez les compteurs de participants, de soumissions et de copies non soumises sur votre écran. Le suivi se rafraîchit toutes les cinq secondes lorsque la page est visible. Une actualisation ou une nouvelle ouverture de la page conserve l’étape et l’heure de fin du chronomètre.
6. Annoncez la fin, puis cliquez sur **Fermer la collecte** pour le panel ou **Terminer le temps de réponse** pour les étudiants. Le chronomètre est indicatif : il ne ferme pas la séance et ne soumet pas de brouillon automatiquement. Une copie non soumise conserve ce statut, sans note de zéro.
7. Pour le panel, présentez les distributions, puis générez et validez le corrigé après avoir vérifié le barème. Les experts ayant soumis voient déjà leurs choix face au panel anonyme, même si les autres répondent encore. Pour les étudiants, affichez d’abord la comparaison étudiants–experts, puis les corrigés une impression clinique à la fois. **Publier les résultats** rend ensuite disponibles les notes globales personnelles et la distribution anonyme du groupe.

Les étapes ne peuvent pas revenir en arrière après l’ouverture des réponses ; une collecte fermée ne se rouvre pas. Les commandes sont réservées au propriétaire ou à un collaborateur disposant des droits de gestion des séances. Le serveur refuse aussi les sauvegardes et les soumissions anticipées, indépendamment de l’interface.

Les séances synchrones déjà créées avant cette évolution gardent leur fonctionnement immédiat. Les séances asynchrones autorisées par le professeur et les essais restent également accessibles immédiatement. La nouvelle salle d’attente concerne les nouveaux lancements synchrones effectués depuis l’interface. Aucune migration SQL ni nouvelle variable d’environnement n’est nécessaire : les étapes sont conservées dans les métadonnées existantes de la séance.
